# OpsPilot

> One-line description: An AI assistant that answers employees' questions from their company's own documents, with citations, and escalates to a person when needed.

> **How to write:** The README is the repository's "front door". A recruiter will spend roughly 30 seconds here. Include a screenshot/GIF right at the top. Write this at the end (as the project progresses); if any section is left blank, write "Coming soon".

**Status:** In development (Phase 1: Foundation)

## Why this project

Employees waste time searching for rules or interrupting colleagues. OpsPilot gives them a sourced answer in seconds. See [Problem Statement](docs/01-problem-statement.md).
